# Daksh Bubble Floaters (Sorting Race Game)

An interactive sorting race and visualizer web application built with Next.js, React, Tailwind CSS, and TypeScript.

## 🚀 Features

- **Sorting Race Game**: Real-time visual comparison and race between sorting algorithms (Bubble Sort, etc.).
- **Versus Mode**: Play and challenge sorting algorithms interactively.
- **Modern UI**: Styled with Tailwind CSS and Radix/Lucide icons.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/), Radix UI, Lucide Icons
- **Language**: TypeScript

## 🏁 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- `npm` / `pnpm` / `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/DikshantDuggal/daksh-bubble-floaters.git
cd daksh-bubble-floaters

# Install dependencies
npm install
# or
pnpm install

# Run the development server
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
